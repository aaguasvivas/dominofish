# DominoFish evaluation report

Generated by `dominofish report` from docs/eval/results/; do not edit by hand. Every result here is self-play between DominoFish's own bots and engines: relative strength only, not a measure against people. Each row is a match of duplicate pairs (one deal played twice with the sides swapping seats) on held-out deal seeds; A is the first side. Points per round are side A's points minus side B's, per round; the game-win rate is side A's share of games won. Unit round plays round 1 of each game only; unit game plays each game to its target. Intervals are 95%: a t interval over pairs for points per round, and a Wilson score interval over the games for the game-win rate. The SPRT is on the pair margin (H0 and H1 are mean pair margins in points, alpha = beta = 0.05), or, where its bounds say wins, on each pair's share of games won by A; its outcome is the first boundary crossing, and a run that never crosses is inconclusive. Peak RSS is the maximum resident set size that /usr/bin/time -l reports for the match command; it is not a total over the engine processes. Milliseconds per move run from the referee's go to side A's move (a record, not a budget; - for runs before it was recorded). The corrected result subtracts AIVAT control variates (docs/PLAN.md D19) with coefficients fitted on the other half of the pairs, which keeps its mean; - for runs without --aivat.
